├────────────────────────────────────────────────────────────────────────────┤

│   → Accepts minimal or full payload                                        │
│   → Returns comprehensive 9-section response                               │

┌────────────────────────────────────────────────────────────────────────────┐
│ 📥 REQUEST SCHEMA (EventPredictionRequest)                                │
├────────────────────────────────────────────────────────────────────────────┤
│ REQUIRED FIELDS:                                                           │
│   • event_type: str                                                        │
│   • event_cause: str                                                       │
│   • latitude: float                                                        │
│   • longitude: float                                                       │
│   • requires_road_closure: bool                                            │
│   • event_datetime: str (ISO 8601)                                         │
│                                                                            │
│ OPTIONAL (AUTO-CALCULATED OR DEFAULTED):                                   │
│   • zone: Optional[str] = None           ← AUTO-CALCULATED                │
│   • junction: Optional[str] = None       ← AUTO-CALCULATED                │
│   • corridor: Optional[str] = None       ← Defaults to "No Corridor"      │
│   • police_station: Optional[str] = "Unknown"                              │
│   • veh_type: Optional[str] = "Unknown"                                    │
│   • authenticated: Optional[str] = "True"                                  │
│   • available_resources: AvailableResources = {}  ← Defaults to 0s        │
│       - officers, marshals, barricades, tow_vehicles, ambulances           │
└────────────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────────────┐
│ 📤 RESPONSE SCHEMA (PredictionResponse)                                   │
├────────────────────────────────────────────────────────────────────────────┤
│ 1. EVENT:             Event metadata (type, cause, location, datetime)    │
│ 2. LOCATION:          Zone, junction, distance                            │
│ 3. TRAFFIC:           Real-time speed, congestion, confidence             │
│ 4. SEVERITY_SCORE:    ML prediction (0-100)                               │
│ 5. HOTSPOT_SCORE:     Historical incident density                         │
│ 6. JUNCTION_SCORE:    Junction importance ranking                         │
│ 7. CLOSURE_SCORE:     Road closure impact                                 │
│ 8. RISK_SCORE:        Weighted composite (0-100)                          │
│    RISK_CATEGORY:     LOW / MEDIUM / HIGH / CRITICAL                      │
│ 9. RESOURCES:         LLM-powered allocation                              │
│    - allocation_priority                                                   │
│    - recommended_resources (5 types)                                       │
│    - resource_gap (shortfall analysis)                                     │
│    - reasoning (LLM explanation)                                           │
└────────────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────────────┐
│ 🔄 DATA FLOW                                                               │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│  1. Receive Request                                                        │
│           ↓                                                                │
│  2. Auto-enrich Location (zone + junction from lat/lon)                   │
│           ↓                                                                │
│  3. Engineer Features (27 temporal + spatial features)                    │
│           ↓                                                                │
│  4. ML Prediction (CatBoost → severity score)                             │
│           ↓                                                                │
│  5. Fetch Traffic (TomTom API → traffic score)                            │
│           ↓                                                                │
│  6. Compute Risk (5-factor weighted scoring)                              │
│           ↓                                                                │
│  7. LLM Allocation (Gemini → resource recommendations)                    │
│           ↓                                                                │
│  8. Assemble Response (9-section structured JSON)                         │
│           ↓                                                                │
│  9. Return to Client                                                       │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────────────┐
│ 📊 RISK SCORING FORMULA                                                    │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│  risk_score = 0.25 × severity_score    (ML prediction)                    │
│             + 0.25 × hotspot_score     (Historical density)               │
│             + 0.20 × junction_score    (Importance ranking)               │
│             + 0.10 × closure_score     (Road closure impact)              │
│             + 0.20 × traffic_score     (Real-time congestion)             │
│                                                                            │
│  CATEGORIES:                                                               │
│    0-25   → LOW       (Minor incident, minimal resources)                 │
│    25-50  → MEDIUM    (Standard response)                                 │
│    50-75  → HIGH      (Priority response)                                 │
│    75-100 → CRITICAL  (Maximum resources)                                 │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
